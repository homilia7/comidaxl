# 🍔 Comida Callejera XL — Sitio Web Oficial & Pedidos Online

Plataforma gastronómica de alto rendimiento para **Comida Callejera XL** (Costa Rica). 

Diseñada con un estándar visual moderno inspirado en **Foodies**, destacando sus porciones monumentales de más de 500 gramos, el emblemático túnel de luces neón LED en Heredia y su catálogo de comida urbana.

## ⚡ Tecnologías
- **Framework:** [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconografía:** [Lucide Icons](https://lucide.dev/)
- **Hosting:** [Cloudflare Pages](https://pages.cloudflare.com/)

---

## 🛠️ Comandos de Desarrollo
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
